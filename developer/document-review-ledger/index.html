    PR #301 문서별 검토 기록¶

    이 기록은 문서 정비 이슈 #299의 문서별 검토 범위를 보여 준다. 원래 PR #301의 비교 기준 0e59d362에 있던 추적 Markdown 66개를 파일별로 대조했다. 그중 59개를 수정하고 7개는 보존했다. 표의 근거는 읽은 코드·설정·이슈 또는 해당 시점의 기록이며, 배포 환경에서 그 기능을 새로 실행했다는 뜻이 아니다. main 15665df와 검증된 로컬 통합 04a35a7의 코드를 대조했다. 로컬 #317·#310·#320은 main 병합이나 운영 적용을 완료한 것으로 적지 않는다.

    현재는 저장소 코드·작업 규칙, 목표는 향후 설계, 승인 대기는 정책 결정이 필요한 내용, 운영 미확인은 실제 환경의 DB·Blob·OAuth·Preview 설정을 이번 문서 검토에서 확인하지 않았다는 뜻이다. 과거 기록은 해당 날짜의 조사·테스트 수치를 유지한다. 표의 수정은 내용이나 읽기 경로를 고쳤다는 뜻이며, 코드·DB·운영 데이터를 바꿨다는 뜻이 아니다.
