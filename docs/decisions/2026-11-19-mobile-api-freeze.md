# 결정 기록: 모바일 앱·API v1 동결 (2026-11-19)

> 상태: **확정** · 결정일: 2026-11-19 · 근거 이슈: #491 · 결정자: 프로젝트 소유자

## 결정

모바일 앱과 공용 API v1을 **동결(freeze)** 합니다. 삭제하지 않고 현재 상태로 보존하며, 보안 패치와 의존성 갱신만 수행합니다. Web 운영이 우선이며 [1인 운영 원칙](../operations/solo-operations.md)을 따릅니다.

## 배경

- 최근 실제 학생·운영진의 앱 수요와 향후 학기 사용 계획이 확인되지 않았습니다.
- 스토어 출시·서명·실기기 QA·Push·EAS·종속성 보안 갱신은 1인 운영 기준으로 지속 유지 비용이 큽니다.
- 선택지 중 A(출시 계속), C(별도 저장소 분리)는 비용·위험 대비 근거가 부족해 택하지 않고, **B(유지하되 신규 기능 동결)** 를 택했습니다.

## 유지하는 것 (보안 패치·의존성 갱신만)

- `apps/mobile` Android MVP 코드와 `packages/contracts`
- `/api/v1` 라우트와 OpenAPI 계약
- 모바일 세션·Bearer 토큰 어댑터, `mobile_sessions` 스키마와 관련 CI
- 인증·업로드 경계, 공개 접근 차단 검사 (완화하지 않음)

## 운영 규칙

- 모바일 세션 정리 cron은 **등록하지 않습니다** ([예약 작업](../operations/cron-jobs.md)).
- 운영 `mobile_sessions` 테이블·기존 세션 데이터를 임의로 삭제하지 않습니다.
- 새 모바일 기능·API v1 엔드포인트·EAS 환경·Push·iOS 작업은 이 기록을 갱신하는 재개 결정 전에는 시작하지 않습니다.

## 내부 설치 테스트 예외

2026-11-20 소유자 요청으로 **1회성 내부 설치 확인**을 허용합니다(#573). 재개 결정이 아니며 위 중단 항목은 그대로입니다.

- `모바일 Android` 워크플로의 수동 입력으로만 release APK를 만들고(main, 운영 비밀값 없음, 산출물 7일 보관) 기기에 직접 설치해 확인합니다.
- 스토어 업로드·EAS 환경·Push·iOS·신규 모바일 기능·API v1 엔드포인트는 계속 중단합니다.
- 서명은 공개 debug keystore이므로 외부 배포에 쓰지 않습니다. 공개 저장소라 산출물은 보관 기간(7일) 동안 GitHub 로그인 사용자가 내려받을 수 있으므로 확인 후 즉시 삭제하고 테스트 계정 세션을 폐기합니다.
