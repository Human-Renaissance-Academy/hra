# 기존 자료실의 역할별 이용 흐름

> [#603](https://github.com/Human-Renaissance-Academy/hra/issues/603) 검토안 · 2026-11-24 · 기준 코드 `ba70c35`

학생은 내 기수의 학습자료, 교수는 강의자료 등록, 관리자는 자료 등록과 기존 관리자 기능으로 먼저 이동한다. 진입점은 기존 `/resources`와 `/admin`을 사용한다. 공개 홈페이지의 메뉴 구조, 로그인 후 이동, `/mypage`, 기존 자료 상세 URL을 보존한다. 승인 대기는 계정 상태이며 학사 승인자·검토자·운영 인력의 인가는 별도로 관리한다.

## 웹 첫 화면과 기본 선택

| 계정 | 첫 행동과 자료 | 전체 자료의 제안 기본값 | 빈 상태 |
| --- | --- | --- | --- |
| 학생 · 기수 배정 | **내 학습자료 보기** → 주차별 텍스트. 가이드북 바로가기와 허용 자료 최근 최대 3건 | 본인 기수 · 주차별 텍스트 → 주차별 수업일지 → 강의 자료 → 가이드북 → 보고서 양식. 전체 기수를 선택해 공동 수업일지 등을 탐색할 수 있음 | 본인 기수에 자료가 없으면 해당 조건에 자료가 없다고 안내하고 가이드북 등 허용 자료 탐색 제공 |
| 학생 · 기수 미배정 | **공통 강의자료 보기** → 학생용 강의 자료. 가이드북 바로가기 | 전체 기수 · 강의 자료 → 가이드북 → 보고서 양식 → 주차별 수업일지 → 주차별 텍스트 | “기수가 배정되지 않았습니다. 공통 자료를 이용할 수 있습니다.” 주차별 텍스트 선택 시 배정 안내. 기수별 작성 동선은 배정된 학생에게 제공 |
| 교수 | **강의자료 등록** → `/resources/class-materials`. 강의자료 목록과 최근 강의자료 최대 3건 | 전체 기수 · 강의 자료 → 주차별 텍스트 → 주차별 수업일지 → 가이드북 → 보고서 양식 | “등록된 강의자료가 없습니다.” 등록 동선 제공 |
| 관리자 | `/resources`의 기존 자료 등록·미리보기. 회원 승인·기수·콘텐츠 관리는 `/admin`에서 진행 | 전체 기수 · 가이드북 → 강의 자료 → 주차별 텍스트 → 주차별 수업일지 → 보고서 양식 | 현재 검색·필터에 자료가 없다고 안내하고 조건을 바꿀 수 있게 제공 |
| 승인 대기 · 비로그인 | 각각 `/pending`, `/login` | 자료 목록 조회 전에 이동 | 승인 대기에서 관리자가 승인하면 다음 요청에서 현재 계정 상태로 다시 인가 |

순서의 첫 항목을 기본 분류로 선택한다. 기존 유효한 `/resources?category=…`는 기본 분류에 우선하고 알 수 없는 값은 기본 분류로 돌아간다. 검색·기수 선택·분류별 하위 필터·페이지 이동을 유지한다. 분류에 따라 공통 가이드북·강의자료·보고서 양식도 기수 목록에서 볼 수 있다. 교수·관리자는 대상 필터에서 학생용·교수용을 탐색하며 학생에게는 학생용만 조회된다.

## 화면 배치와 복귀

같은 내용과 읽기 순서를 화면 폭에 맞춰 배치한다. 일정은 회원용 조회 경로와 표시 범위가 확인된 경우에 한해 한 건을 표시한다. 담당 수업 연결이 검증된 일정에만 “내 강의” 표기를 쓴다. 현재 웹의 첫 화면은 자료 바로가기부터 시작한다.

```text
데스크톱 (1280px, 기존 헤더)
학생 / 자료실 · 내 기수
[내 학습자료 보기] [가이드북]  | 최근 학습자료 최대 3건
[분류 5개] [내 기수 ▼] [검색]  → 결과 · 페이지 이동

교수 / 자료실
[강의자료 등록] [강의자료 목록] | 최근 강의자료 최대 3건
[분류 5개] [전체 ▼] [대상 ▼] [검색] → 결과 · 페이지 이동

관리자 / 자료실
[관리자 자료실] [교수 미리보기] [학생 미리보기]
[수업일지 추가] [텍스트 추가] [가이드북 추가]
[분류 5개] [전체 ▼] [검색]     → 결과 · 페이지 이동

모바일 웹 (각 예시 320~390px, 기존 헤더, 한 열)
학생                    교수                     관리자
자료실 · 내 기수        자료실                   자료실
[내 학습자료 보기]      [강의자료 등록]          [관리자/교수/학생 모드]
[가이드북]              [강의자료 목록]          [기존 자료 등록 링크]
최근 학습자료           최근 강의자료            자료 목록
분류 · 기수 · 검색      분류 · 기수 · 대상 · 검색  분류 · 기수 · 검색
결과 카드               결과 카드                결과 카드

공통 전환 상태
승인 대기 → 기존 승인 안내 / 비로그인 → 기존 로그인 화면
기수 미배정 학생 → 배정 안내 한 줄 / [공통 강의자료 보기] [가이드북]
```

- 기본 방문은 역할별 첫 화면 → 바로가기 → 분류 목록 → 기존 상세 또는 다운로드 순서다. 자료 상세 주소로 직접 진입하는 경우에도 상세·파일 서버가 현재 권한을 확인한다.
- 브라우저 뒤로가기는 직전 목록 분류를 복원한다. 상세의 명시적 목록 링크는 기존 `category` 계약으로 해당 분류를 선택하도록 검토한다. 검색·기수·페이지의 복원 동작은 브라우저 뒤로가기와 직접 URL 진입을 나눠 확인한다. 현재 목록의 탭·검색·페이지 상태는 클라이언트에서 관리한다.
- Android는 홈의 조회 가능한 다음 일정 한 건과 역할별 주요 행동에서 자료 또는 과제로 연결한다. 자료 탭은 가이드북 목록과 인증 다운로드를 제공한다. 교수 앱의 강의자료 등록은 지원 경로와 인가를 검증한 별도 범위로 둔다.

## 권한과 학사 표시

아래 셀은 **열람 / 작성·등록 / 보호 파일 내려받기** 순서다. 파일이 있는 자료에만 다운로드가 적용된다. 편집·삭제·발행은 각 기존 기능의 인가를 따른다. [공동 자료](../resource-access-policy.md) · [파일 전달](../resource-file-access-policy.md)

| 강의 자료 | 학생용 / — / 학생용 | 같음 | 학생용·교수용 / 등록 / 학생용·교수용 | 같음 |
| 주차별 텍스트 | 본인 기수 / 본인 기수 / 본인 기수 | — / — / — | 모든 기수·공통 / 가능 / 모든 기수·공통 | 같음 |

승인 대기·비로그인은 보호 자료의 열람·작성·다운로드 모두 불가하다. 학생의 타 기수·공통 주차별 텍스트는 상세·인쇄·첨부·사진을 포함해 404로 처리한다. Web 쿠키와 Android Bearer는 공용 서버 인가를 사용한다. 역할·기수 변경, 승인 취소 및 로그인 계정 교체 후 기존 세션의 요청과 캐시에서 이전 권한의 자료가 나타나는지 확인한다.

G1 운영 미활성 상태의 자료실에는 학적·과제 링크와 제출 통계를 표시하지 않는다. 운영 승인과 해당 서버 설정이 확인되고 본인 학적과 공개 대상 과제를 서버가 검증한 경우에만 학생의 과제 동선을 연결할 수 있다. 교수 검토에는 별도 활성 설정과 지정 검토 권한이 필요하다. 사이트 관리자 역할로 학사 관리 권한이 생기지 않는다. 출결·피드백·수료는 각 학사 결정에 따른다. [학사 로드맵](../ACADEMIC-MANAGEMENT-ROADMAP.md) · [과제 제출 범위](../ASSIGNMENT-SUBMISSION-SCOPE.md)

[#621](https://github.com/Human-Renaissance-Academy/hra/issues/621)의 주차별 안내는 별도 작업이다. 첫 단계는 운영자가 확인된 32개 주차의 최소 메타데이터를 비공개 원본과 대조하고 미확정 구간을 표시하는 것이다. 검수된 최소 메타데이터만 사용하고 원본 PDF, 연락처, 학생 명단, 제출물, 비공개 파일 주소를 문서·이슈·PR에 싣지 않는다. 겨울학습 미확정 기간은 미확정으로 표시한다. 실제 게시·DB 적재 전 기존 운영 승인 절차를 적용한다.

## 검토와 검증

- [ ] **흐름** — 학생·교수는 첫 화면에서 한 번의 동작으로 주 행동에 이동한다. 관리자는 기존 자료 등록과 관리자 메뉴를 쓸 수 있고 미리보기가 서버 주체를 바꾸지 않는다. 공개 홈페이지·전역 메뉴·로그인 후 이동·`/mypage`·기존 상세 URL을 확인한다.
- [ ] **목록 회귀** — 역할별 분류 순서와 초기 기수, 유효·무효 분류 쿼리, 검색·하위 필터·페이지 이동, 작성과 다운로드, 상세의 목록 링크와 브라우저 뒤로가기를 확인한다. 미배정·자료 없음·조회 오류는 각 상황에 맞는 안내를 표시한다.
- [ ] **서버 권한** — 격리 데이터로 학생 본인/타 기수·미배정, 교수, 관리자, 승인 대기, 비로그인에서 목록·직접 URL·파일을 Web 쿠키와 API v1 Bearer 양쪽에서 확인한다. 역할 강등, 기수 이동, 승인 취소, 계정 삭제·로그아웃 후 현재 권한을 재확인한다. 비활성 학사 플래그 및 미지정 교수는 동선과 보호 응답 양쪽에서 확인한다.
- [ ] **웹 화면** — 320·375·390·768·1280px에서 가로 넘침, 긴 제목, 터치·키보드 포커스·스크린리더 이름을 확인한다. `tests/e2e/resources-responsive.spec.ts`, `tests/unit/resource-portal.test.tsx`, `tests/unit/resources-tabs.test.ts`의 검증을 활용한다.
- [ ] **Android 화면** — 작은 화면·큰 글씨·안전 영역과 홈↔자료·공지 딥링크·뒤로가기·오프라인·계정 전환을 확인한다. `apps/mobile/tests/home-screen.test.tsx`, `apps/mobile/tests/resources-screen.test.tsx` 및 #579 실기기 검증을 활용한다.

검토 승인 후 남은 웹 작업은 역할별 분류·기수 기본값과 상세 복귀 흐름으로 나눠 검증할 수 있다. Android 자료 종류 확대는 기존 계약·캐시·인가를 확인한 뒤 별도로 검토하며, [Android 출시 재개 결정](../decisions/2026-11-20-android-play-release-resume.md)의 필수 범위에 추가하는 선행 조건으로 두지 않는다. 구현·운영 설정 변경·DB 적용은 각각 해당 후속 결정에서 다룬다.
